TK / WORLD PROTOTYPE 06

Open index.html in a current browser. No installation or server is required.
Images, environments, interaction code and project data are included in the standalone file.

THIS VERSION
A photographic, single-player exploration prototype with six connected viewpoints and a hidden motion room. The earlier heuristic depth mesh has been removed because it distorted the architecture. A rigid image stage now uses bounded pan/approach and synchronized display anchors. This is cinematic image navigation, not free-roaming 3D geometry or an MMORPG.

ART DIRECTION
Sport, preparation, precision, and movement run through the practice. The display system uses original fine contour graphics, ivory paper, folio numbering, and discreet discovery stamps inspired by contemporary passport design.
A quiet coastal campus with sculptural architecture, light, water and dramatic photographic spaces, derived from the user's supplied architectural references. Five environment plates were generated for this world. These are invented architecture, not photographs of an existing campus.
The TK monogram sculpture has been removed. There is no Fieldnotes or Avant Le Nom content section.

CONTROLS
Click location markers or use the bottom navigation to travel.
Drag the environment to look around. Double click to reset the viewpoint.
W / Up arrow steps forward; holding continues the approach and enters the next scene.
A / D strafe. Left / Right arrows turn. S / Down backs away. Click the floor or use the wheel to approach a display.
E inspects the nearest installation or follows a nearby route. M opens/closes the world map.
Touch movement controls appear on small screens.
Click installations to open project records. Windows can be dragged, expanded, restored and closed.
Focus a window title bar and use arrow keys to move it. Shift makes larger moves.
Escape closes an image viewer, map or the foremost window.
Sound is optional, synthesized ambient audio; it starts only on request.
Location discovery is saved only in the current browser using local storage. No accounts or analytics are added.
